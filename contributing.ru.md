+++
title = "Как внести вклад"
weight = 3
description = "Как предложить изменение."
+++

- `main` всегда чистый и готов к релизу — без артефактов, нужных только для
  разработки. Повседневная работа — в `develop`; крупные изменения и фиксы
  багов — в отдельных ветках от `develop`.
- Предложить изменение — через issue, реализовать в отдельной ветке, открыть
  pull request в `develop`.

Про версионирование, конвенцию архив+GitHub Release, хотфиксы и ночную сборку —
см. [Релизы](../releases/).

*(Эта страница со временем вырастет в полноценное руководство для
контрибьюторов.)*
